# diapause_plasticity_temp

This repository has the data and code for analyzing diapause responses of *D. carinulata* in two experiments, in 2020 and 2022.

File structure:  
`plasticity_experiment_data` contains the raw data from the 2020 and 2022 diapause experiments  
`data_derived` contains data that is generated by the scripts  
`scripts` contains the R code to analyze the data  
`plots` contains graphs of the data, as generated by the R scripts
